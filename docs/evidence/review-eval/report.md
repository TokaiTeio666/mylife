## 已知口径

- 语义用例的 `S11_long_note_tail` 故意把错误放在候选 800 字符截断之后，
  用于暴露“长段落证据截断导致漏检”的现有边界；
- `S09_multi_items` 用于暴露“共享根因的不同事故被合并成一条”的提示词边界；
- `action_generation` 的失败项是产品缺口（错误/方法论未转为行动条目），
  不是评测脚本缺陷；显式 action 条目的正向对照会正常通过；
- 单次运行受模型采样影响；基准建议使用 `--repeat 3`，分数用于回归比较而非绝对排名；
- 未启用 `--llm` 时，语义/字段/可追溯三项不参与总分，权重按剩余维度归一化。
